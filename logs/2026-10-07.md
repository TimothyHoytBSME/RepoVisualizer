## Architecture (quick map)

- `src/langs.js`: per-language rules (definition regexes, import extractors, comment/string masking, keywords). `mask()` blanks comments/strings while keeping offsets. `wanted()` filters files to load.
- `src/analyze.js`: builds the graph `{nodes, edges}`. Nodes: dir, file, lib, and symbols (class/type/module/function/method/variable). Edges: `contain` (structure), `dep` (resolved use/import, drawn with arrows), `ref` (ambiguous name match, plain line). Body ranges come from indentation (`blockEnd`). Params and function-local variables shadow global names (`localsOf`). Import resolution per language in `makeResolver`.
- `src/worker.js`: runs `analyze` off the main thread (falls back to main thread if module workers fail).
- `src/graph.js`: `buildView` makes a map type (`code` = files+symbols+libs, `files` = dirs+files+libs with symbol edges lifted to files). `neighborhood` = BFS to the depth slider value.
- `src/layout.js`: force layout (Barnes-Hut repulsion, springs, radial rings by depth around the selected node, which is pinned). Positions persist per view.
- `src/render.js`: WebGL2 instanced nodes/edges/arrowheads + Canvas2D labels with collision grid. Colors come from CSS variables (`readPalette`).
- `src/controls.js`: pointer (pan, pinch, tap, long-press peek, wheel), keyboard, gamepad.
- `src/panel.js`: details panel (code in context with highlighting and clickable identifiers, relation lists) and hover peek.
- `src/source.js` + `src/zip.js`: GitHub loading (1 API call for the tree, then raw.githubusercontent.com), local zip/folder/drag-drop.
- `src/main.js`: app state, selection, camera, search, dialogs, URL state (`?repo=&node=&map=&depth=`), `window.__rv` test hook (`__rv.loadFiles([{path,text}])`).

- Analyzer can be run directly in Node (pure ES module) on cloned repos.
