## Architecture (quick map)

- `src/langs.js`: per-language rules. Each language object has `group`, `exts`, `syntax` (comment/string masking: `line`, `block`, `quotes`, `triple`, `charQuote`, `template` = quote chars with `${}`, `dollarId`, `raw`, `multi`, `regex`, `hashWord`), `defs` ([regex with group 1 = name, kind, optional filter fn, keep flag]), `extra(masked)` for code-based detection (cfuncs, goGroups, goMethods with `owner`), `imports(raw, masked)`, `resolve` (resolver key), `kw`, `id`, plus optional `explicit`, `pkgDir`, `flatVars`, `paramLast`, `shadowExt`, `priv`, `pkg`, `strip`, `head`, `prep` (Vue/Svelte/Astro SFC), `localDecl` (typed local declarations), `anon` (anonymous function/block param regexes), `binds` (JS/Python import bindings), `sigil` (PHP `$`), `extRecv` (Kotlin extension receiver), `syntax.rawHash`/`verbatim`/`rawCpp`/`hashRaw`/`heredoc`. Def kinds `impl`/`extension`/`prop` are container-only or unindexed variants. `mask()` blanks comments and strings, keeping offsets. `wanted()` filters files.
- `src/analyze.js`: graph = `{nodes, edges: {s, t, type: Uint8Array (1 ref, 2 contain, 3 dep)}, stats}`. Linking (per identifier): member detection (`.`/`->`/`::`, receiver word or call), receiver type from anon scopes / `typesOf` (params, locals, `()call` return types) / `fieldTypes` / `selfOf`+`ownerOf` (Go/Rust), class members via `memberIn` (own then `basesOf`), `COMMON` built-in names skipped, then imported (incl. facade re-exports, C include closure) / package / global fallback (none for bare names in module files). Nodes: dir, file, lib, keyword, class/type/module/function/method/variable (`impl` defs are containers only). Body ranges come from indentation (`blockEnd`, with per-language skip lines). Params and locals shadow global names. Per-file `local` names and private defs; global `names` by group. `makeResolver` handles imports per language (go.mod, crate roots, python packages, jvm package dirs + symbol lookup, …). `keywords()` builds keyword nodes. Edges go out as transferable typed arrays.
- `src/graph.js`: `indexGraph` (CSR in/out, byKey), `edgesOf`, `buildView(g, type, filters)` for `code`/`files`/`dirs`/`words`, `neighborhood(v, sel, depth, limit, dir)` (budgeted BFS with `total`, `hidden` counts; `dir` both/out/in), `shortestPath`, `withPath`, `edgeBetween`, `defaultNode`, `isTest`.
- `src/layout.js`: Barnes-Hut force layout with depth bands. `layout-worker.js` runs it off the main thread; `layout-host.js` is the main-thread proxy (does the initial `place()`, streams positions, `onFresh` callback, falls back to a local Layout).
- `src/render.js`: WebGL2 instanced nodes (shape packed into the ring attribute), edges and arrowheads; persistent buffers; repacks only when `[nb, sel, hl, hover, pal, ver]` changes; context-loss recovery; Canvas2D labels with a collision grid.
- `src/controls.js`: pointer (pan, pinch, tap, long-press peek, wheel, Safari gesture events), keyboard, gamepad (`makeGamepad`).
- `src/panel.js`: details panel, peek, code highlighting, keyword mentions, line-click navigation, back/forward/share buttons. All repo text must go through `esc()`.
- `src/source.js` + `src/zip.js` + `src/cache.js`: GitHub listing (ref/sub splits), verified downloads with retries, offline fallback, local zip (read by slices) / folder / drop scanning, saved repos (IndexedDB v2 stores: blobs by sha, small repos records, files lists).
- `src/main.js`: app state and wiring. Selection (`select`, `app.selectGlobal` auto-reveals filtered nodes), camera follow/goto/fit, the idle render loop (`app.dirty` setter → `kick()`), search, dialogs, filters/limit/theme, URL and history state, drop handling, sheet drag, `window.__rv` test hook.
- `sw.js`: versioned shell precache (`VERSION`, `SHELL`). **Add new src files to SHELL and bump VERSION when adding files.**
